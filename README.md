# EstateDesk CRM

EstateDesk is a multi-tenant estate agency CRM built using the MERN stack.  
The system allows real estate agencies to manage properties, contacts and team members inside separate workspaces.

---

## Features

- User Authentication (JWT + Cookies)
- Multi-Tenant Workspace Architecture
- Role Based Access Control (Owner, Admin, Agent, Viewer)
- Property Management
- Contact Management
- Membership System
- Tenant Middleware Security
- React Dashboard Layout

---

## Tech Stack

Frontend
- React.js
- React Router
- CSS Modules

Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

---

## Architecture

This project uses a multi-tenant SaaS architecture where each workspace (tenant) has its own data for properties, contacts and members.
